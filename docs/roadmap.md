# CNomarchy 开发路线图

## 阶段 0：项目骨架与构建流水线（第 1-2 周）

**目标**：能构建出可引导 ISO，启动后进入基本桌面。

- [x] 项目目录结构
- [x] README + 架构文档 + 路线图
- [ ] archiso profile（profiledef.sh, packages.x86_64, pacman.conf）
- [ ] 构建脚本（build-iso.sh, setup-build-env.sh）
- [ ] 基础系统定制（locale、时区、用户、自动登录）
- [ ] Hyprland 最小配置
- [ ] QEMU 测试脚本
- [ ] **里程碑**：build-iso.sh 产出 ISO，VM 中能引导进入 Hyprland

## 阶段 1：Omarchy 桌面集成（第 3-4 周）

**目标**：集成 Quickshell 和 Agent 框架，达到 Omarchy 基础体验。

- [ ] 确认 Omarchy 软件源地址并配置
- [ ] 安装 Quickshell + Omarchy 桌面元包
- [ ] 部署 Omarchy 默认配置
- [ ] Agent Harness 基础配置（快捷键、权限）
- [ ] 接入 DeepSeek API（第一个可用模型）
- [ ] **里程碑**：进入 Quickshell 桌面，快捷键唤起 Agent，DeepSeek 能执行简单操作

## 阶段 2：中国化基础（第 5-6 周）

**目标**：中文环境开箱即用。

- [ ] Fcitx5 中文输入法（拼音引擎、搜狗词库、皮肤）

- [ ] Arch 国内镜像源（清华 TUNA / 中科大 USTC）

- [ ] 预装国产软件（Flatpak：微信、QQ、钉钉、飞书、WPS）
- [ ] Chromium 中文默认设置
- [ ] **里程碑**：全新安装开机能打中文、微信/钉钉/WPS 一键安装

## 阶段 3：手机号身份服务（第 7-10 周）

**目标**：手机号登录 + 配置云同步 + 多设备管理。

- [ ] 后端认证服务（FastAPI）：发码、验证、JWT
- [ ] 阿里云短信接入
- [ ] 客户端登录界面
- [ ] 配置云同步（Git：登录 pull，变更 push）
- [ ] 设备管理（ID 生成、绑定、列表、注销）
- [ ] 换手机号流程
- [ ] Token 过期与刷新
- [ ] **里程碑**：两台设备同号登录配置自动同步；新设备登录需短信确认

## 阶段 4：五层兼容架构（第 11-16 周）

- **L1（第11周）**：Flatpak 常用软件清单 + 一键安装 + 软件安装器 GUI

- **L3（第14周）**：Bottles + Steam + 兼容性数据库 + 常用软件一键脚本
- **L4（第15周）**：Chromium App 模式封装 + 常用网站 PWA 清单
- **L5（第16周）**：远程桌面客户端 + 云主机配置向导 + RemoteApp 模式
- [ ] **里程碑**：搜索任何软件自动推荐最优方案一键安装

## 一人 + AI 执行说明

所有代码/配置/脚本/文档由 AI 编写产出，人类负责：
1. 在 Linux 构建环境执行构建脚本
2. 在 VM/真机测试，反馈问题
3. 关键技术决策拍板
4. 商务操作（注册公司、ICP、等保、云服务、短信服务）
5. 社区运营和用户反馈

构建失败或运行问题时，人类把错误日志贴给 AI，AI 分析修复，人类重新构建。迭代推进。
